# Metrics Schema Specification

This document defines the schema of the performance evaluation artifacts (`summary.json`) generated by `objeta-qwen36-executor`. Maintaining this schema ensures that downstream experiment comparison matrices can parse and track benchmarks correctly across optimizations.

## `summary.json` Schema

Every run must write a flat `summary.json` containing the following required fields.

| Field Name | Type | Description |
|---|---|---|
| `strategy_name` | `string` | The active strategy name (e.g. `safe`, `fast`, `turbo`). |
| `git_commit` | `string` | Git SHA-1 hash of the commit this run was executed on. |
| `model_id` | `string` | Model identifier (e.g., `qwen3.6-35b-a3b`). |
| `prompt_hash` | `string` | First 8 characters of the SHA-256 hash of the prompt. |
| `tok_s` | `float` | Decoding throughput in tokens per second. |
| `total_wall_ms` | `float` | Total generation decoding wall time in milliseconds. |
| `forward_wall_ms_avg` | `float` | Average forward-pass wall time per token in milliseconds. |
| `moe_wall_ms_avg` | `float` | Average MoE layer computation wall time per token in milliseconds. |
| `non_moe_wall_ms_avg` | `float` | Average non-MoE computation wall time per token (calculated as `forward_wall_ms_avg - moe_wall_ms_avg`). |
| `moe_fraction` | `float` | Ratio of MoE wall time to total forward wall time. |
| `avg_experts_per_layer` | `float` | Average number of executed experts per layer. |
| `avg_bytes_read` | `float` | Average number of model bytes read from expert weights per layer. |
| `warm_hit_rate` | `float` | Warm hit rate of the RAM-resident expert page cache (0.0 to 100.0). |
| `cold_load_count` | `integer` | Total number of cold expert cache misses loaded from cold/mmap storage. |
| `first_garbage` | `object` or `null` | Info dictionary about the first garbage token: `{"char_index": integer, "char": string}`, or `null`. |
| `first_repetition` | `object` or `null` | Info dictionary about the first repetition pattern: `{"step": integer, "token_id": integer, "first_seen": integer}`, or `null`. |
| `entropy_first` | `float` | Attention entropy of the first generated token. |
| `entropy_last` | `float` | Attention entropy of the last generated token. |
| `entropy_min` | `float` | Minimum attention entropy observed during the run. |
| `entropy_max` | `float` | Maximum attention entropy observed during the run. |

## `metrics.jsonl` Schema

For step-by-step telemetry, the executor appends a JSON line for every decoded token.

Required fields per line:
* `step` (`integer`): Decode iteration index (1-based).
* `token_id` (`integer`): ID of the decoded token.
* `entropy` (`float`): Attention entropy at this step.
* `step_time_ms` (`float`): Wall time to process this single token step.
* `cache_warm_hits` (`integer`): Cumulative warm cache hits.
* `cache_cold_loads` (`integer`): Cumulative cold expert loads.
