# Metrics Schema Specification

This document defines the schema of the performance evaluation artifacts generated by `objeta-qwen36-executor`.

## `summary.json` Schema

Every run must write a flat `summary.json` containing the following required fields.

### Core Performance Fields

| Field | Type | Description |
|-------|------|-------------|
| `strategy_name` | `string` | Active strategy name (e.g. `safe_exact`). |
| `git_commit` | `string` | Git SHA-1 hash. |
| `model_id` | `string` | Model identifier (e.g., `Qwen3.6-35B-A3B`). |
| `prompt_hash` | `string` | First 8 chars of SHA-256 of the prompt. |
| `tok_s` | `float` | Decoding throughput (tokens/sec). |
| `total_wall_ms` | `float` | Total generation wall time (ms). |
| `forward_wall_ms_avg` | `float` | Average forward-pass wall time per token (ms). |
| `moe_wall_ms_avg` | `float` | Average MoE layer wall time per token (ms). |
| `non_moe_wall_ms_avg` | `float` | `forward_wall_ms_avg - moe_wall_ms_avg`. |
| `moe_fraction` | `float` | Ratio of MoE wall to total forward wall. |
| `avg_experts_per_layer` | `float` | Average executed experts per layer. |
| `avg_bytes_read` | `float` | Average expert bytes read per layer. |

### Byte Telemetry Fields

> [!IMPORTANT]
> The following invariant must hold for every run:
> `logical_expert_bytes_requested = actual_expert_bytes_loaded + resident_cache_bytes_reused`

| Field | Type | Description |
|-------|------|-------------|
| `logical_expert_bytes_requested` | `integer` | Total compressed Q4 bytes logically needed for all expert calls across all layers/tokens. |
| `actual_expert_bytes_loaded` | `integer` | Bytes actually loaded from mmap/SSD (cache misses). |
| `resident_cache_bytes_reused` | `integer` | Bytes served from RAM-resident cache (cache hits). |
| `resident_cache_resident_bytes` | `integer` | Current resident cache footprint at run end (bytes). |
| `dequantized_scratch_bytes` | `integer` | Bytes of F32 scratch allocated for dequantization. `0` for `FusedQ4` path. |

### Resident Cache Stats

| Field | Type | Description |
|-------|------|-------------|
| `resident_cache_enabled` | `bool` | `true` if capacity > 0. |
| `resident_cache_capacity_bytes` | `integer` | Configured capacity in bytes. |
| `resident_cache_hit_count` | `integer` | Total cache hit count. |
| `resident_cache_miss_count` | `integer` | Total cache miss count. |
| `resident_cache_hit_rate` | `float` | `hit_count / (hit_count + miss_count)`. |
| `direct_cold_load_count` | `integer` | Count of cold loads (miss + loaded from source). |
| `warm_hit_rate` | `float` | `warm_hits / (warm_hits + cold_hits)`. |
| `cold_load_count` | `integer` | Total cold loads (alias for `direct_cold_load_count`). |

### Backend / Runtime Fields

| Field | Type | Description |
|-------|------|-------------|
| `use_fused_moe` | `bool` | Whether `FusedQ4` backend is active. |
| `fused_moe_variant` | `string` | Fused down-projection variant (`row_parallel`, `chunked128`, etc.). |

### Quality Fields

| Field | Type | Description |
|-------|------|-------------|
| `warm_hit_rate` | `float` | Warm cache hit rate. |
| `first_garbage` | `object\|null` | `{"char_index": int, "char": str}` or null. |
| `first_repetition` | `object\|null` | `{"step": int, "token_id": int, "first_seen": int}` or null. |
| `entropy_first` | `float` | Entropy at first generated token. |
| `entropy_last` | `float` | Entropy at last generated token. |
| `entropy_min` | `float` | Minimum entropy. |
| `entropy_max` | `float` | Maximum entropy. |
| `aborted` | `bool` | Whether generation was early-aborted. |
| `abort_reason` | `string\|null` | Reason for early abort. |

## `moe_stats.json` Schema

The `moe_stats.json` file is produced by `lko_runner_get_moe_stats_json()` and written by the Python runner.

### Top-level structure

```json
{
  "summary": { ... },         // Aggregate across all layers/tokens
  "forward_summary": { ... }, // Forward pass timing
  "layers": [ ... ],          // Per-layer aggregate stats (40 entries)
  "forward_layers": [ ... ],  // Per-layer forward timing
  "moe_io_events": [ ... ],   // Per-token/per-layer I/O events
  "effective_policy": { ... },
  "effective_runtime": { ... }
}
```

### `summary` Object

Includes all byte telemetry fields (see above) plus timing averages:

| Field | Description |
|-------|-------------|
| `avg_call_moe_wall_ms` | Full `call_moe_pipeline` wall (router → cache → exec → stats) |
| `avg_router_wall_ms` | Router top-k time |
| `avg_candidate_build_wall_ms` | Building `Vec<SelectedExpert>` |
| `avg_policy_select_wall_ms` | Adaptive policy hook (passive stub) |
| `avg_cache_lookup_wall_ms` | Residency cache resolution |
| `avg_routed_exec_wall_ms` | Backend dispatch + execution |
| `avg_stats_wall_ms` | Telemetry finalization |
| `avg_fused_gate_up_ms` | Gate+Up projection (FusedQ4 only) |
| `avg_fused_swiglu_ms` | SwiGLU activation (FusedQ4 only) |
| `avg_fused_down_accum_ms` | Down projection + accumulation (FusedQ4 only) |

### `layers[]` Entry

Each entry covers one MoE layer (40 total). Key fields:

| Field | Description |
|-------|-------------|
| `logical_expert_bytes_requested` | Total Q4 bytes needed for this layer |
| `actual_expert_bytes_loaded` | Bytes loaded from source (misses) |
| `resident_cache_bytes_reused` | Bytes reused from cache (hits) |
| `resident_cache_resident_bytes` | Cache size attributed to this layer |
| `dequantized_scratch_bytes` | F32 scratch for this layer (0 if FusedQ4) |
| `avg_call_moe_wall_ms` | Wall time per call for this layer |
| `unique_expert_ids` | Set of expert IDs ever selected |
| `last_selected_ids` | Expert IDs in most recent call |

### `moe_io_events[]` Entry

One entry per `(step, layer_id)` pair. Key fields:

| Field | Description |
|-------|-------------|
| `step` | Decode step (0 = prefill) |
| `token_id` | Input token ID |
| `layer_id` | Layer index (0–39) |
| `selected_experts` | Expert IDs selected for this call |
| `logical_expert_bytes_requested` | Q4 bytes needed |
| `actual_expert_bytes_loaded` | Bytes loaded from source |
| `resident_cache_bytes_reused` | Bytes from cache |
| `resident_cache_resident_bytes` | Cache size at this point |
| `eviction_count` | Evictions triggered by this call |
| `dequantized_scratch_bytes` | F32 scratch (0 if FusedQ4) |

## `metrics.jsonl` Schema

Step-by-step telemetry. One JSON line per decoded token:

| Field | Type | Description |
|-------|------|-------------|
| `step` | `integer` | Decode step (1-based). |
| `token_id` | `integer` | Decoded token ID. |
| `entropy` | `float` | Router entropy at this step. |
| `step_time_ms` | `float` | Wall time for this step (ms). |
| `cache_warm_hits` | `integer` | Cumulative warm cache hits. |
| `cache_cold_loads` | `integer` | Cumulative cold loads. |

Additionally, `moe_io` events from `moe_io_events` are appended:

```jsonl
{"event": "moe_io", "step": 1, "layer_id": 3, "logical_expert_bytes_requested": 3456789, ...}
```
